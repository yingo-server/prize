抽奖应用 功能逻辑说明书（供重写 2D 版参考，零 UI 细节）
========================================================

一、视图与状态机
----------------
三个视图：home(首页) / wheel(转盘) / wall(红包墙)
状态 phase：idle → spinning(转盘转动中) / flipped(红包翻开中) → scratched(刮层可刮)
        → verify(人机验证中) → result(结果弹窗) → penalty-hold(惩罚重抽倒计时) → retrying → idle

流转：
- idle --拖拽甩盘/拖拽翻红包--> spinning/scratched
- spinning --盘面物理停止--> result（转盘）
- scratched --刮开60% 或点击确认全显--> result（红包墙）
- result --抽中惩罚且人机验证开启--> verify（暂停500ms弹验证）--> 答对 --> result 展示
- result --抽中被禁用惩罚(红包墙)--> penalty-hold（2s倒计时）--> retrying（新种子重抽）--> result
- result --确认--> idle
- 任意状态 --重置--> idle（库存/次数/种子全清）

二、数据模型
----------------
奖品项：{ id, name, stock, weight, isPenalty }
配置（单 JSON 文件，运行时 fetch，缺失回退内置默认）：
{
  转盘设置: { 转动时长毫秒, 最少旋转圈数 },   // 3D 版该字段仅作参考，物理决定一切
  红包墙设置: { 红包数量 },
  惩罚项: { 已启用 },
  人机验证: { 已启用, 时长毫秒, 问候语[], 通过语[], 范围[a,b] },
  奖品: [...]
}

三、随机与公平
----------------
- 每次抽取生成 4×u32 种子，全程可复现（种子文本展示给用户）
- 加权抽取：候选池 = 奖品中 stock>0 且 (!isPenalty || 惩罚已启用)，按 weight 加权
- 奖池为空：若惩罚已启用则自动关闭惩罚开关再取；仍空则提示
- 红包墙网格用种子 Fisher-Yates 洗牌决定红包初始排列

四、转盘逻辑（手势直驱）
----------------
1. 无开始按钮。用户按住盘面（射线/坐标换算出盘面角度）拖拽：
   - 盘角度严格跟随手指角度增量（跟手）
   - 指尖瞬时角速度做低通滤波
2. 松手：指尖速度成为盘初速 ω0（有上限钳制）。|ω0| 太小(<1.2rad/s)则不算抽奖
3. 之后纯物理演化：
   - 减速力矩 = 轴承摩擦(常数 τ=μ·m·g·r/2) + 空气阻力(∝ω²)
   - ω 被摩擦积分到 0 时精确刹停（静摩擦，不反转）
4. 停止后结果 = 指针（12点）所在扇区索引。力度决定结果，无预设无目标角
5. 指针物理：弹簧-阻尼摆（θ''=-kθ-cθ'），盘每跨一枚分隔钉给指针一次与钉线速度
   成正比的冲量（拨动效果），限位挡块按恢复系数反弹
6. 盘停止 + 指针静止 → onSpinDone(扇区索引) → 进入结果流程

五、红包墙逻辑（拖拽翻面）
----------------
1. 红包数量 N = min(配置.红包数量, 有效奖品种类数)；列数：N≤6→3列，≤8→4列，>8→6列
2. 每张卡初始绑定一个待翻位置（洗牌序），翻开那一刻才真正抽取并绑定奖品
3. 交互：按住卡横拖 → 卡绕底边翻转（角速度∝拖动速度）：
   - 翻过重心角(0.51π) → 被卡扣捕获翻到 π（背面）→ 翻面成功
   - 没过重心松手 → 重力力矩翻回正面（可重试）
4. 翻面成功瞬间：drawFor() 抽奖绑定该卡 → 显示背面刮层 → 进入 scratched
5. 刮层：Canvas destination-out，指针移动轨迹刮除（半径渐进），进度采样
   （每隔若干次移动统计 alpha<128 占比）≥60% 自动全显；或点击已刮卡=确认全显
6. 全显 → onPacketRevealed → 结果流程

六、结果流程（两种玩法共用）
----------------
1. 抽中非惩罚：扣库存(stock-1) → 播放对应音效/特效 → 弹结果窗（奖品名/剩余库存/种子文本/确认按钮）
2. 抽中惩罚且人机验证开启：
   a. phase=verify，暂停 500ms（配置.时长毫秒）
   b. 弹验证窗：随机问候语 + 随机加减法（操作数取配置.范围，减法保证非负）
   c. 答错：提示"机器人检测+1"抖动，可重试；答对：随机通过语 → 继续
3. 红包墙特有——抽中惩罚且惩罚被禁用（即池里混入后开关被切）：
   弹窗显示惩罚内容 + "已禁用惩罚项，自动重抽"2s 倒计时 → 该卡重置为未开 → 新种子重抽
   （被禁惩罚全程不扣库存）
4. 结果窗关闭 → phase=idle，可继续抽

七、音效清单（WebAudio 合成，无音频文件）
----------------
click(按钮) / toggleOn toggleOff(开关) / spinStart spinLoop(转动循环,音调随速度) /
decelTick(跨钉咔哒) / win(中奖琶音) / penalty(惩罚低音) / retry(重抽提示) /
scratch(刮擦,节流) / coinBurst(金币爆出) / reset(重置下行三音)
背景音乐：五声音阶循环，独立开关，页面隐藏时暂停
主音量开关只控 masterGain(0.35/0)

八、特效
----------------
常态：80颗飘落金粒子
中奖：彩带140 + 金币雨60 + 烟花3组×24射线 + 光柱冲击波 + 屏幕震动
刮开：碎屑粒子 + 20枚金币从卡中心爆出
低性能模式：以上全关；灯泡/粒数减半；阴影/体积光关闭

九、降级链
----------------
WASM(随机数/粒子步进)失败 → JS 等价实现
WebGL 不可用 → 不可进 3D 视图（2D 版无此依赖）
AudioContext 需首次 pointerdown 解锁

十、HUD 控件（全部功能，无多余）
----------------
音效开关（胶囊，aria-pressed 同步状态）
惩罚项开关（胶囊：开=惩罚生效，关=禁用+抽中重抽）
全屏切换
重置本场
视图切换（首页/转盘/红包墙）

十一、config.json 运行时加载
----------------
fetch('config.json', {cache:'no-store'})，字段级归一化合并默认值，
fetch 失败(file://或缺失)回退内置默认 → 改奖品零构建零后端
